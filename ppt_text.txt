System Architecture: Resilient API Fetching & Crontab
1. Decoupled Architecture (Zero-Crash Policy)
• Independent Background Crontab: Fetches data from APIs every 15 minutes, completely isolated from the Next.js Frontend and FastAPI backend.
• No UI Blocking: Frontend never waits for slow government APIs; it instantly reads pre-processed data from the local SQLite Database.
2. Multi-Tier Fallback Mechanism
• Primary (CPCB) → Fallback 1 (OpenAQ) → Fallback 2 (WAQI / AQICN).
• Graceful Degradation: If one API is down or keys expire, it silently cascades to the next.
3. Honest AI Philosophy (Real Data > Fake Data)
• If all government APIs experience prolonged outages (>2 hours), the system honestly breaks the 24h streak and reverts to a Demo Fallback instead of corrupting the XGBoost model with fabricated synthetic data.
