# VayuSangam Demo API

Start the backend from `vayu-sangam/`:

```bash
venv/bin/uvicorn backend.app.main:app --reload
```

Interactive OpenAPI documentation is available at `http://localhost:8000/docs`.
All data is synthetic demo data and every primary response contains provenance
fields (`mode`, `data_source`, `model`, `model_version`, and/or
`scientific_status`).

## Primary Phase 6 endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/health` | Demo assets and services readiness |
| GET | `/api/forecast?hours=72` | Hourly domain-mean forecast timeline |
| GET | `/api/forecast/grid?hour=24&variable=pm25` | One spatial field for the map |
| GET | `/api/sources?hour=24` | Ranked DBSCAN fire-source clusters |
| GET | `/api/inversion?hour=24` | Delhi-NCR inversion/trapping result |
| POST | `/api/scenario` | Stubble-reduction comparison |
| GET | `/api/explanation?hour=24` | Rules-based evidence summary |

`hour` is an integer from 0 through 72. Invalid values produce HTTP 422.

### Forecast timeline

`GET /api/forecast?hours=72` returns `forecast`, an array of hourly records:

```json
{
  "hour": 24,
  "timestamp": "2026-11-02T00:00:00",
  "pm25_ug_m3": 139.0,
  "pm10_ug_m3": 222.4,
  "o3_ug_m3": 2.3,
  "nox_ug_m3": 55.6,
  "temperature_c": 8.8,
  "wind_speed_mps": 2.92,
  "pbl_height_m": 201.8,
  "aqi": 315
}
```

### Grid map layer

`variable` is whitelisted to: `pm25`, `pm10`, `o3`, `nox`, `pblh`, `t2`, and
`rh`. The response contains matching `lat`, `lon`, and row-major `values`
arrays. Use `units` to label the selected layer.

### Source intelligence

`GET /api/sources` returns `sources`, ordered by `source_score`. Each cluster
includes `centroid`, fire/FRP aggregates, HCHO evidence, wind information,
wind-alignment score, distance, travel-time range, and score components. The
score is explicitly a prototype heuristic, not calibrated attribution.

### Scenario request

```json
POST /api/scenario
{
  "stubble_reduction": 0.3,
  "hour": 24
}
```

`stubble_reduction` is in `[0, 1]`: `0` is baseline and `0.3` represents a
30% reduction. The response provides baseline/scenario PM2.5, PM10, O3, AQI,
sub-indices, deltas, and peak-hour comparison. In this demo, O3 is unchanged
by the stubble slider; this is stated in the response `note`.

## Compatibility routes

The Phase 1 frontend can continue using `/api/forecast/72-hours` and
`/api/explainability`. They now return deterministic data generated by the
new engines. New Phase 7 UI work should use the primary endpoints above.
